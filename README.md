# ShopWave 🛍️

เว็บแอปร้านค้าออนไลน์ภาษาไทย สไตล์มาร์เก็ตเพลสมินิมอลโทนน้ำเงินเข้ม สร้างด้วย **React + Vite + Tailwind CSS**
ดึงข้อมูลสินค้าจริง 194 รายการจาก [DummyJSON](https://dummyjson.com) และมีระบบครบตั้งแต่ค้นหา ตะกร้า สมาชิก ไปจนถึงชำระเงินด้วย PromptPay QR

> โปรเจกต์นี้เป็นร้านค้าสาธิตสำหรับพอร์ตโฟลิโอ ไม่มีการขายสินค้าหรือเรียกเก็บเงินจริง

## เทคโนโลยีที่ใช้

| ส่วน | เครื่องมือ |
| --- | --- |
| Framework / Build | React, Vite |
| สไตล์ | Tailwind CSS v4 (ผ่านปลั๊กอิน `@tailwindcss/vite`) |
| Routing | React Router DOM v6+ |
| State + localStorage | Zustand (middleware `persist`) |
| ไอคอน | Lucide React |
| QR PromptPay | `qrcode.react` |
| ข้อมูลสินค้า | DummyJSON (ไม่ต้องใช้ API key) |
| ฟอนต์ | IBM Plex Sans Thai (Google Fonts) |

ต้องใช้ **Node.js 18 ขึ้นไป** และต่ออินเทอร์เน็ตตอนติดตั้งแพ็กเกจและตอนเปิดเว็บ (เพื่อโหลดข้อมูลสินค้า รูปภาพ และฟอนต์)

## เริ่มต้นใช้งาน

> ชุดไฟล์ในโฟลเดอร์นี้ไม่มี `package.json` และ `node_modules` ให้สร้างโปรเจกต์ Vite เปล่าก่อน แล้วนำไฟล์มาวางตามขั้นตอนด้านล่าง
> (ถ้าคุณมีโปรเจกต์ที่ติดตั้งแพ็กเกจครบแล้ว ข้ามไปขั้นคัดลอกไฟล์ได้เลย)

### สร้างโปรเจกต์ Vite แล้วนำไฟล์มาวาง

```bash
# 1) สร้างโปรเจกต์
npm create vite@latest shopwave-th -- --template react
cd shopwave-th
npm install

# 2) ติดตั้งแพ็กเกจที่ต้องใช้
npm install react-router-dom zustand lucide-react qrcode.react
npm install tailwindcss @tailwindcss/vite

# 3) ลบไฟล์ตัวอย่างของ Vite
rm -f src/App.css src/assets/react.svg
```

จากนั้นคัดลอกไฟล์/โฟลเดอร์เหล่านี้จาก zip ไป **ทับ** ในโปรเจกต์ใหม่

```
src/
public/
index.html
vite.config.js
vercel.json
.env.example
```

แล้วรัน

```bash
cp .env.example .env
npm run dev
```

เปิดเบราว์เซอร์ที่ `http://localhost:5173`

## ตัวแปรสภาพแวดล้อม (.env)

คัดลอก `.env.example` เป็น `.env` แล้วแก้ค่าได้

| ตัวแปร | ค่าเริ่มต้น | คำอธิบาย |
| --- | --- | --- |
| `VITE_PROMPTPAY_ID` | `0000000000` | เบอร์พร้อมเพย์ 10 หลัก หรือเลขบัตรประชาชน 13 หลัก ที่ใช้สร้าง QR |

ค่าเริ่มต้นเป็นเลขสมมติที่รับเงินจริงไม่ได้ เพื่อป้องกันการโอนเงินผิดคนตอนสาธิต
ถ้าต้องการทดสอบสแกนด้วยแอปธนาคาร ให้ใส่เบอร์ของตัวเอง (ข้อควรระวัง: ถ้าสแกนแล้วกดโอน เงินจะเข้าบัญชีนั้นจริง)

หลังแก้ `.env` ต้องหยุดแล้วรัน `npm run dev` ใหม่

## ฟีเจอร์

**หน้าแรก**
- แบนเนอร์หลักเลื่อนอัตโนมัติ (หยุดเมื่อเอาเมาส์ชี้ และเคารพการตั้งค่าลดการเคลื่อนไหวของระบบ)
- หมวดหมู่ยอดนิยม ดีลเด็ดวันนี้ ร้านแบรนด์ยอดนิยม แบนเนอร์โปรโมชั่น
- แบนเนอร์นับถอยหลังถึงเที่ยงคืน พร้อมปุ่มคัดลอกโค้ดส่วนลด
- แถวสินค้าขายดีแยกตามหมวด และ "สินค้าที่คุณดูล่าสุด"

**ค้นหาและเลือกดูสินค้า**
- ช่องค้นหามีคำแนะนำสินค้าขณะพิมพ์ ค้นได้ทั้งภาษาไทยและอังกฤษ (ชื่อ แบรนด์ หมวด แท็ก)
- หมวดหมู่ 7 กลุ่ม 24 หมวดย่อย พร้อมเมกะเมนู
- ตัวกรอง: หมวดหมู่ ช่วงราคา แบรนด์ คะแนนรีวิว เฉพาะลดราคา เฉพาะพร้อมส่ง
- เรียงตาม: แนะนำ / ราคาต่ำ–สูง / ราคาสูง–ต่ำ / คะแนน / ลดมากที่สุด
- แบ่งหน้าละ 20 รายการ
- ตัวกรองทั้งหมดอยู่ใน URL จึงแชร์ลิงก์และกดย้อนกลับได้
- มือถือแสดงตัวกรองเป็นหน้าต่างเลื่อนขึ้นจากด้านล่าง

**รายละเอียดสินค้า**
- แกลเลอรีรูปหลายภาพ ราคาเดิม/ราคาลด สถานะสต็อก
- เลือกจำนวน เพิ่มลงตะกร้า หรือกด "ซื้อเลย"
- แท็บรายละเอียดและรีวิว สินค้าที่คล้ายกัน

**ตะกร้าและโค้ดส่วนลด**
- เปิดดูได้ทั้งแบบแผงด้านข้าง (Drawer) และหน้า `/cart`
- เพิ่ม/ลดจำนวน (จำกัดตามสต็อก สูงสุด 20 ชิ้นต่อรายการ) ลบสินค้า ล้างตะกร้า
- แถบความคืบหน้า "ซื้อเพิ่มอีก ฿xxx รับส่งฟรี"
- คำนวณยอดสินค้า ส่วนลด ค่าจัดส่ง และ VAT อัตโนมัติ
- ตะกร้าและโค้ดที่ใช้ถูกเก็บใน `localStorage` ปิดเบราว์เซอร์แล้วเปิดใหม่ยังอยู่

**สมาชิก**
- สมัครสมาชิก เข้าสู่ระบบ ออกจากระบบ แก้ไขชื่อและเบอร์โทร
- จดจำที่อยู่จัดส่งล่าสุดไว้กรอกอัตโนมัติ
- ประวัติคำสั่งซื้อ
- รายการโปรด (ไม่ต้องล็อกอินก็ใช้ได้)

**ชำระเงิน**
- ที่อยู่ไทย: เลือกจากทั้ง 77 จังหวัด ตรวจรูปแบบเบอร์โทร (ขึ้นต้น 0, 9–10 หลัก) และรหัสไปรษณีย์ 5 หลัก
- ตรวจข้อมูลเมื่อออกจากช่อง (blur) และเมื่อกดยืนยัน โดยโฟกัสไปที่ช่องที่ผิดช่องแรก
- เลือกวิธีจัดส่ง: ธรรมดา (฿50 ส่งฟรีเมื่อครบ ฿999) หรือด่วนพิเศษ (฿120)
- เลือกวิธีชำระเงิน
  - **พร้อมเพย์:** สร้าง QR ตามมาตรฐาน EMVCo พร้อมยอดเงินและ CRC ที่ถูกต้อง
  - **บัตรเครดิต/เดบิต:** ตรวจเลขบัตรด้วย Luhn ตรวจวันหมดอายุและ CVV (เก็บเฉพาะเลข 4 ตัวท้าย)
  - **เก็บเงินปลายทาง**
- หน้ายืนยันคำสั่งซื้อพร้อมเลขที่ออเดอร์ และล้างตะกร้าให้อัตโนมัติ

**อื่น ๆ**
- Toast แจ้งเตือนเมื่อเพิ่มสินค้า (มีปุ่มลัด "ดูตะกร้า")
- Skeleton ระหว่างโหลดข้อมูล และหน้าแสดงข้อผิดพลาดพร้อมปุ่ม "ลองอีกครั้ง"
- Responsive แบบ mobile-first รองรับการใช้งานด้วยคีย์บอร์ดและ screen reader (ARIA)

## หน้าเว็บทั้งหมด (Routes)

| Path | หน้า | หมายเหตุ |
| --- | --- | --- |
| `/` | หน้าแรก | |
| `/products` | รายการสินค้า | พารามิเตอร์: `q`, `group`, `category`, `brand`, `min`, `max`, `rating`, `deal`, `stock`, `sort`, `page` |
| `/product/:id` | รายละเอียดสินค้า | |
| `/cart` | ตะกร้าสินค้า | |
| `/checkout` | ชำระเงิน | ตะกร้าว่างจะถูกส่งกลับ `/cart` |
| `/order/:id` | สรุป/ชำระเงินคำสั่งซื้อ | แสดง QR ถ้าสถานะรอชำระเงิน |
| `/wishlist` | รายการโปรด | |
| `/login` | เข้าสู่ระบบ / สมัครสมาชิก | รองรับ `?next=/path` |
| `/account` | บัญชีและคำสั่งซื้อ | ต้องเข้าสู่ระบบ |

ตัวอย่างลิงก์: `/products?group=electronics&brand=Apple&sort=price-asc`

## ข้อมูลสำหรับทดลองใช้

**โค้ดส่วนลด**

| โค้ด | ผลลัพธ์ |
| --- | --- |
| `SAVE10` | ลด 10% (สูงสุด ฿500) |
| `WELCOME100` | ลด ฿100 เมื่อซื้อครบ ฿1,000 |
| `FREESHIP` | ส่งฟรี (จัดส่งธรรมดา) |

**บัตรทดสอบ**

| ช่อง | ค่า |
| --- | --- |
| เลขบัตร | `4242 4242 4242 4242` |
| วันหมดอายุ | วันที่ในอนาคต เช่น `12/30` |
| CVV | `123` |

**ขั้นตอนทดสอบการชำระด้วยพร้อมเพย์**
1. เพิ่มสินค้าลงตะกร้า แล้วไปที่ชำระเงิน
2. เลือก "พร้อมเพย์" กรอกข้อมูลแล้วกดสั่งซื้อ
3. หน้าคำสั่งซื้อจะแสดง QR และสถานะ "รอชำระเงิน"
4. กด "จำลองการชำระเงินสำเร็จ" สถานะจะเปลี่ยนเป็น "ชำระเงินแล้ว"

## การทำงานภายใน

**ข้อมูลสินค้า** (`services/api.js`)
เรียก `https://dummyjson.com/products?limit=0` ครั้งเดียวเพื่อได้สินค้าทั้งหมด แล้วเก็บผลไว้ในหน่วยความจำ
การค้นหา กรอง เรียง และแบ่งหน้าทำฝั่ง client จึงตอบสนองทันที หน้ารายละเอียดสินค้าก็ใช้ข้อมูลชุดเดียวกัน

**ราคา** (`utils/pricing.js`)
- แปลง USD เป็นบาทที่ `USD_TO_THB = 35` (แก้ได้ใน `services/api.js`)
- ราคาที่แสดงเป็นราคารวม VAT 7% แล้ว ส่วนบรรทัด VAT คือยอดภาษีที่แฝงอยู่ในยอดรวม
- ส่งฟรีเมื่อยอดหลังหักส่วนลดครบ ฿999 (เฉพาะจัดส่งธรรมดา)
- เพิ่มหรือแก้โค้ดส่วนลดได้ที่ `COUPONS` ในไฟล์เดียวกัน

**การเก็บข้อมูลในเบราว์เซอร์** (localStorage)

| Key | เนื้อหา |
| --- | --- |
| `shopwave-cart` | สินค้าในตะกร้า + โค้ดส่วนลด |
| `shopwave-auth` | บัญชีสมาชิกจำลอง (รหัสผ่านแฮช SHA-256) |
| `shopwave-orders` | คำสั่งซื้อ |
| `shopwave-wishlist` / `shopwave-recent` / `shopwave-ui` | รายการโปรด / สินค้าที่ดูล่าสุด / จังหวัดที่เลือก |

ล้างข้อมูลทั้งหมดได้จาก DevTools → Application → Local Storage

**PromptPay QR** (`services/promptpay.js`)
สร้างข้อความ QR ตามมาตรฐาน Thai QR Payment (EMVCo) ประกอบด้วยรหัสผู้รับ ยอดเงิน และ CRC16 แล้วให้ `qrcode.react` วาดเป็นภาพ

## Deploy

```bash
npm run build
```

อัปโหลดโฟลเดอร์ `dist/` ไปยังบริการที่ชอบ

- **Vercel:** มี `vercel.json` ให้แล้ว
- **Netlify:** มี `public/_redirects` ให้แล้ว
- **เจ้าอื่น / เซิร์ฟเวอร์เอง:** ต้องตั้งให้ทุก path ตอบกลับ `index.html` มิฉะนั้นรีเฟรชหน้า `/product/5` จะขึ้น 404

ถ้าตั้งค่า `VITE_PROMPTPAY_ID` ให้ใส่ใน Environment Variables ของบริการที่ deploy ด้วย

## ข้อจำกัดที่ควรรู้

- **ไม่มี backend:** บัญชีสมาชิก คำสั่งซื้อ และสต็อก เก็บและตรวจที่ฝั่งเบราว์เซอร์เท่านั้น ใครเปิด DevTools ก็แก้ได้ ใช้เพื่อสาธิตเท่านั้น
- **การชำระเงินเป็นแบบจำลอง:** ไม่มีการตัดบัตรหรือตรวจว่าเงินเข้าจริง ถ้าจะใช้งานจริงต้องเชื่อมผู้ให้บริการชำระเงิน เช่น Omise หรือ Stripe และให้ backend ยืนยันการชำระเงิน
- **ชื่อสินค้าและรีวิวเป็นภาษาอังกฤษ:** เพราะมาจาก DummyJSON ส่วนอินเทอร์เฟซและชื่อหมวดเป็นภาษาไทย
- **ข้อมูลรีวิวต่อสินค้ามีน้อย** (ประมาณ 3 รีวิว) ตามที่ API ให้มา
- ไม่ควรกรอกรหัสผ่านหรือข้อมูลบัตรจริงในระบบนี้

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
| --- | --- |
| หน้าเว็บไม่มีสไตล์ | ตรวจว่าติดตั้ง `tailwindcss` และ `@tailwindcss/vite` แล้ว และ `vite.config.js` มี `tailwindcss()` ใน plugins |
| `Failed to resolve import "qrcode.react"` | รัน `npm install qrcode.react` |
| โหลดสินค้าไม่ขึ้น / ขึ้นข้อความผิดพลาด | ตรวจอินเทอร์เน็ต หรือเปิด `https://dummyjson.com/products` ว่าเข้าได้หรือไม่ แล้วกด "ลองอีกครั้ง" |
| รีเฟรชแล้วเจอ 404 หลัง deploy | ตั้ง SPA rewrite ตามหัวข้อ Deploy |
| แก้ `.env` แล้วไม่เปลี่ยน | หยุดแล้วรัน `npm run dev` ใหม่ |
| ข้อมูลตะกร้า/สมาชิกค้างจากการทดสอบ | ล้าง Local Storage ของเว็บใน DevTools |
